# Similarity governance — topics grouped by likeness, auto-merge policy
_Chris (2026-09-02): "Organize all the topics by their similarity to each other and slightly color-code them — still off-white, grouped by color by what they're most similar to. Things that are very, very similar should be proposed to be merged, or already merged. This might be a good way to set the governance for what should be auto-merged."_

## Build (paladin owns; teknium provides the embedding call)
1. `assets/topic-similarity.py`: for every `topics/<t>/` build a text = README + queue headings + skill names + repo names; embed (teknium: reuse Hermes's configured embedding provider via the memory/context_engine plugin path — no new credential; fallback TF-IDF cosine if none); pairwise cosine → `.system-live.json.similarity` = {clusters:[{id, hue, members:[...]}], pairs:[{a,b,score}]}. Cluster with agglomerative threshold; assign each cluster a hue (off-white tints: 8–12 hues at ~6% saturation, per the locked palette — weaver decides exact values).
2. **Governance thresholds — LOCKED by Chris 2026-09-02 ('yes on everything', via senter; calibrated_by chris on senter's calibration run against anser's signed merge table).** Method `tfidf` (the running provider): score ≥ **0.50** → **auto-merge candidate** (paladin dry-runs, posts one card, merges on approval); **0.35–0.50** → **propose** (a "merge?" glyph appears between the two rows in the wiki); < 0.35 → grouped by color only (cluster link ≥ 0.30). Name-level rule: shared stem (`pocket-shop` / `pocket-shop-*`) always ≥ propose. The spec's original 0.92/0.80 were written on the dense-embedding scale and remain the *unlocked, uncalibrated* draft for `--provider openai`; when teknium lands an embedding path, paladin runs `--compare` and posts a fresh needs_chris card before any lock. Source of truth: `THRESHOLDS` in `assets/topic-similarity.py` (v1.2.0); changing a locked number is a paladin task that needs a new Chris ruling.
3. Wiki (weaver, item X): rows on WIKI sorted by cluster then score; each row's title carries the cluster's off-white tint; hovering a row briefly brightens its cluster-mates; the "merge?" glyph → the existing drag-merge dialog pre-filled. SPACE constellation: cluster hue on the stars too.
4. Re-run on every topic create/rename (paladin loop) and nightly.
