Chris's new MacBook has a forgotten sudo/login password that was set once during initial setup and never written down.^[raw/inbox/2026-09-12.md] He called it the "pseudo password" in dictation and later said it could be "one of a couple that I rotate between."^[raw/inbox/2026-09-12.md] On 2026-09-12 the password "senterdelta" was tried first and rejected before recovery succeeded.^[raw/inbox/2026-09-12.md] On 2026-09-13 he repeated: "I forgot my sudo password on this macbook. It is mine. I just got it, I set it once, and I did not write it down."^[raw/inbox/2026-09-13.md]

As of 2026-09-14–15 this password is the same one used on the **Omarchy** over Tailscale, so a working sudo on the MacBook is expected to authenticate on the Omarchy too.^[raw/inbox/2026-09-14.md]^[raw/inbox/2026-09-15.md]
