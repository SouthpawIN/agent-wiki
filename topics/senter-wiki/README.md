# Senter Wiki — the surface of a live-acting second brain
`vault-live.html` is *Cursor for markdown*: one page over the GOOP vault (`~/Documents/Projects/Projects`) where every file is an
agentic artifact that can be set in motion — SKILL.md, AGENTS.md, SOUL.md, loop prompts — sitting next to the context that
produced it. Editing a file configures the system. Talking to the sidebar does too: the **watcher** files every message into a
topic within seconds, topic **workers** turn context → skills → bots → loops, and every artifact lands as an **approval card**.
Architecture (Chris, 2026-09-05): [[topics/senter/.system/architecture]]. Spec baseline: `.system/knowledge/spec-agent-wiki.md`
(SouthpawIN/agent-wiki). Fleet orchestrator profile: SouthpawIN/senter.

## The four lanes on this surface
| Lane | UI section | Vault path | Hermes-native write |
|---|---|---|---|
| Context (topics) | TOPICS | `topics/<t>/README.md` + `.system/` | `write_file`, watcher inbox |
| Skills | SKILLS | `topics/<t>/skills/<s>/SKILL.md`, `~/.hermes/skills` | `skill_manage(create)` |
| Bots (agents) | BOTS | `topics/<t>/agents/<a>.md` → `~/.hermes/profiles/<a>` | `hermes profile create` + SOUL.md |
| Loops | LOOPS | `topics/<t>/loops/<l>.md` ↔ `hermes cron` / kanban | `hermes cron create`, `hermes kanban` |
