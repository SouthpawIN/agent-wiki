# Trap Answer vs Correct Answer

Two candidate answers to the bat-and-ball puzzle, and why one fails. ^[raw/inbox/2026-09-15.md]

| Answer | Value | Consistent with "bat $1.00 more"? |
|---|---|---|
| Trap | 10 cents | No — bat would be 90 cents, only 10 cents more |
| Correct | 5 cents | Yes — bat is $1.05, exactly a dollar more |

## The disqualifying check
The trap answer "10 cents" *"only works if the bat cost 90 cents, which contradicts 'a dollar more.'"* ^[raw/inbox/2026-09-15.md] The correct answer passes because $1.05 − $0.05 = $1.00 exactly. ^[raw/inbox/2026-09-15.md]
