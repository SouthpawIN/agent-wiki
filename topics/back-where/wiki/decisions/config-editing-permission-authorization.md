# Config-editing and permission authorization

On 2026-09-13 Chris explicitly authorized Hermes to edit permission configs and to send permissions his way when a gate is hit, saying this is how every permission has been added so far. ^[raw/inbox/2026-09-13.md]

> "You can absolutely edit that config if you need to send a permission and send it my way, but you've done it before. That's how they've all been added. I've really added any of them." ^[raw/inbox/2026-09-13.md]

This operationalizes the device-embodiment framing: Hermes is expected to grant its own access rather than stop at a permission wall. ^[raw/inbox/2026-09-13.md]
