# Agent wiki GitHub backbone

Chris treats his agent wiki GitHub repo as a stable backbone and backup for the theories behind the per-topic wiki model. He thinks something about the nesting of skills into bots into loops may already be represented there. He does not want this structural theory layer to change even as the on-disk layout is simplified. On 2026-09-08 he reaffirmed that the repo is used both as backbone and backup, and that the skills→bots→loops nesting is immutable there.
