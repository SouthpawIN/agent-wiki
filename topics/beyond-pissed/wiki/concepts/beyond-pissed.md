# Beyond Pissed

Chris's stated state regarding missed shipping expectations and unresolved credit/system issues. It functions as both an emotional marker and a non-negotiable urgency signal.

> I am beyond pissed. I was supposed to ship this today, there are people excited for this. This is non-negotiable. ^[raw/inbox/2026-09-06.md]

## Credit Issues
Since there's something wrong with his credits, $2,000 was added. Some has been used, but the balance must cover the project growth. Chris asked to get that fixed because the project has grown up^[raw/inbox/2026-09-06.md].

## Trigger Event — Oh My Archi USB Install (2026-09-12)

The phrase re-appeared on 2026-09-12 when Chris's Oh My Archi USB install on his home lab went badly. He had plugged a USB stick into the MacBook, the machine was stuck in the grub screen, and the ISO write was denied:

> I just unplugged it and plugged it back in again. I bought this for specifically this, and this seems to be going as wrong as a possibly fucking could. I am beyond pissed. ^[raw/inbox/2026-09-12.md]

The failure was a `PermissionError` writing `omarchy-4.0.3.iso` to `/dev/rdisk4` via a raw Python write meant to bypass SIP (see [[topics/beyond-pissed/wiki/entities/oh-my-archi|Oh My Archi]] and [[topics/beyond-pissed/wiki/queries/write-iso-to-usb|Write ISO to USB Without /dev/rdisk4 Permission Error]]).
