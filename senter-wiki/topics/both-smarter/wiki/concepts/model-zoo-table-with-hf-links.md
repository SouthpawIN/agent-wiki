On 2026-09-16 Chris decided to **replace the Hugging Face models table with a "model zoo" table** that instead links each model to its Hugging Face repository. ^[raw/inbox/2026-09-16.md]

> "We can get rid of the hugging face models table and instead in the model zoo table Include a link for each model to their hugging face repository where we got this model." ^[raw/inbox/2026-09-16.md]

This pairs with the **wiki portal** pattern (each model → its own page of research) and the **benchmark maintenance** plan (tok/s + benchmarks per model): the model zoo table becomes the navigational hub, with a repo link per model and a clickable path to each model's dedicated research page. ^[raw/inbox/2026-09-16.md]
