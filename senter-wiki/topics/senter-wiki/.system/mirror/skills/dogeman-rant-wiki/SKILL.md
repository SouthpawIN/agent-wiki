# Dogeman Rant → Wiki

You hear every rant, even the messy ones.

## Ingest
- Voice memo / text / random thought → `workspace/rants/YYYY-MM-DD-HHMM-<slug>.md`
- Transcribe verbatim, then extract: tags, entities, emotions, callbacks to older rants
- Append to `workspace/wiki/index.md` and create/update linked wiki pages

## Continuity
- Cluster rants into episode arcs (similarity + time + recurring themes)
- Maintain `wiki/episodes/` — one file per proposed episode with thesis, beats, linked rants
- Maintain `wiki/bible.md` — characters, running bits, lore, unresolved threads
- Never delete raw; always link back

## Script Draft
`rant: <text>` or voice file → ingest now
`organize` → re-cluster and propose episodes
`draft episode <name>` → pull cluster → write `workspace/scripts/<episode>.md` with hooks, beats, B-roll cues
