## 2026-09-14 13:20 · hermes · 20260913_141606_aa9e49 · sim 0.10
**Quick fixes:**

1. **Cmd+T** — opens a new tab via keyboard
2. **Menu bar** → File → New Tab
3. If you have tabs open, the **+ is at the far right** of the tab bar — it might be scrolled off-screen if you had a lot of tabs
4. If you closed ALL tabs, the tab bar itself hides — use Cmd+T or File → New Tab to bring it back

If none of those work, the window state might be corrupted.
