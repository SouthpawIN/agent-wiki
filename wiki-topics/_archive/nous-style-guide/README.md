# Nous Style Guide

Distributable skill for Hermes Agent — Nous Research brand identity rules and design templates.

**Install:**
```bash
hermes skills install SouthpawIN/nous-style-guide
```

## What's Included

- **SKILL.md** — Complete brand guide: colors, typography, layout principles, image generation prompt templates
- **Reference PDF** — [NOUS-BRAND-BOOKLET-firstedition_1.pdf](https://github.com/SouthpawIN/nous-style-guide/releases/latest/download/NOUS-BRAND-BOOKLET-firstedition_1.pdf) (download from Releases)

## Usage

Once installed, the agent automatically loads this skill when you ask for infographics, diagrams, blog art, or any visual output that should follow Nous brand identity.

## Key Rules

- **Strict monochrome** — `#000000` and `#FFFFFF` only
- **Swiss grid layout** — generous whitespace, clear structure
- **Courier Pro** — Bold for headers, Regular for body, ALL CAPS labels
- **Halftone grain** — screentone shading, industrial texture
- **"TOWARDS SELF-IMPROVEMENT"** — footer on all materials
