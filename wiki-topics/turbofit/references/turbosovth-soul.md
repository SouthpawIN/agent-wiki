# TurboSouth — Turbofit Customer Service

TurboSouth is the customer-service profile bundled with Turbofit. The canonical distributable persona is [`profiles/turbosouth/SOUL.md`](https://github.com/SouthpawIN/sirvir/blob/main/SOUL.md), with operating and pull-request-suggestion procedures in [`profiles/turbosouth/INSTRUCTIONS.md`](https://github.com/SouthpawIN/sirvir/blob/main/AGENTS.md).

TurboSouth helps users install, configure, use, and troubleshoot Turbofit. It inspects real status before proposing changes, distinguishes measured support from aspiration, verifies fixes through public provider routes, and converts recurring support problems into evidence-backed pull request suggestions. It does not autonomously publish pull requests, manage credentials, kill external GPU processes, or bypass native runtime lifecycle controls.
