# Benchmark Infographics

> Freely shareable AI model benchmark comparison infographics with proper sources — the promo/visual layer.

| | |
| --- | --- |
| **Repo** | [benchmark-infographics](https://github.com/SouthpawIN/benchmark-infographics) |
| **Status** | content repo — shareable benchmark visuals |

## What it is

Static infographic assets (e.g. *June 2026: Frontier AI Models* — Claude Opus 4.8 vs GPT-5.5 vs GLM-5.2 vs Qwen3.7 Max vs DeepSeek V4 Pro) with sources listed per figure (LLM Stats, model cards, provider blogs).

## Relation to TurboFit

Feeds the shareable/evidence side of the product — the same benchmark numbers that appear in [benchmark-leaderboard](../../references/benchmark-leaderboard.md) and [external-benchmarks](../../references/external-benchmarks.md). Vault-rendered charts for this topic live at `wiki/models/leaderboard.html` and `wiki/models/hardware-tiers.html`.
