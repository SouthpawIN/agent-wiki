# Decision 2026-09-09: FILE_CAP bypass for .system-live.json

**What.** The senter-bridge server rejected `.system-live.json` with HTTP 413 because the file is ~2.8 MB and the `/file` route enforced a 2 MB `FILE_CAP` limit. Hermes patched the `/file` route to bypass the size cap for `.system-live.json` specifically, since it is the live data contract — not user content.[^raw/inbox/2026-09-09.md]

**Why.** The `.system-live.json` file is the scanner's output contract: it feeds topics, bots, skills, loops, similarity.matrix, and usage data to `vault-live.html`. Without bypass, any change producing a file over 2 MB would fail silently, breaking the live update cycle. The file is generated by `scan-topics.py` and written continuously; its size grows with the vault.[^raw/inbox/2026-09-09.md]
