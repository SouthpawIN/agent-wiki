Based on the source code I just read, here's the **default Hermes Desktop layout** you were referring to:

 

**The three zones (defined in `src/app/contrib/layout-presets.ts`):**

| Zone | Panes | Notes |
|------|-------|-------|
| **Left rail** (weight 1) | `sessions` | The sidebar — pinned recents, projects, worktree. Width 237px default, resizable 237–360px. |
| **Main** (weight 3.4) | `workspace` | The chat surface — your conversation, composer, full-page views (skills, messaging, artifacts, etc.). |
| **Right rail** (weight 1.25) | `review` + `files` stacked over `terminal` | Top: git diff review + file browser. Bottom: terminal. |

**The Bots tab:** The `hermes-bots` plugin registers a pane that **docks center into the sessions zone**, making the left sidebar a tab strip: **SESSIONS | BOTS** (the `enforce: true` dock makes it always stack there at boot, never as a separate split).

**Dynamic panes** that open as tabs within zones (not in the static preset):
- `session-tile:<id>` — a stored session opened from the sidebar
- `preview:*` — file/URL/artifact preview tiles
- Route pages — skills, messaging, artifacts, settings (rendered full-page inside the workspace pane)

That's the default tree: `sessions | workspace | (review/files/terminal)`. Want me to do something specific with this — like build a custom layout preset, write a plugin to modify it, or capture what you're currently running?
