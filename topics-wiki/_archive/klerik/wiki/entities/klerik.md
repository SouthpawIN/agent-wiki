# klerik — the profile factory bot

**What it is.** klerik is the fleet's meta-profile: the one bot allowed to create, refresh and surgically edit other Hermes profiles (SOUL.md / AGENTS.md / skills / config). Senter never edits profiles directly — profile work is always delegated to klerik. Its authoring rules live in `process/agent-authoring-rules.md`; headline rule: *a bot exists when it runs* (a `-q` smoke turn emits `bridge/loaded`), not when its files exist.
