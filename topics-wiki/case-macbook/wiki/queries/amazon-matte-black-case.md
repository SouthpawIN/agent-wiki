# Amazon Matte Black Case Query

Chris's live shopping question.^[raw/inbox/2026-09-16.md]

## The question
> "tell me if I am shopping for the right case, I found a matte black case for this MacBook Pro 14 inch on Amazon, is that what this MacBook is?"

## The answer
- Yes — a matte black case for "MacBook Pro 14 inch" fits Chris's MacBook Pro 14-inch (M1 Pro, 2021). The 14-inch chassis is identical across the M1 Pro/M2 Pro/Max/M3 Pro/Max generations (2021–2024).
- **Condition:** it only fits if the Amazon listing explicitly says "MacBook Pro 14-inch 2021-2024" (or an equivalent 2021–2024 span). A bare "14-inch" label is not enough.
