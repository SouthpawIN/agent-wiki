# MacBook Pro 14-inch (M1 Pro, 2021)

Chris's laptop. He's shopping for a protective case for it, so exact model identity matters — a case must match this chassis, not just any "14-inch MacBook Pro."^[raw/inbox/2026-09-16.md]

## Identity
- **MacBook Pro 14-inch**, M1 Pro, 2021.
- Model identifier: **MacBookPro18,3**.
- **32 GB RAM**.

These specs came from Hermes inspecting the machine (the hermes status block in the same inbox).^[raw/inbox/2026-09-16.md]

## Why it matters here
Chris found a **matte black case for "MacBook Pro 14 inch" on Amazon** and asked whether it's the right case for *this* MacBook. The answer hinges on chassis generation: the M1 Pro 14-inch chassis is physically identical to the M2 Pro/Max 14-inch (2023) and M3 Pro/Max 14-inch (2024) models, so a case labeled "MacBook Pro 14-inch 2021–2024" (or any 14-inch Pro case spanning those years) fits.^[raw/inbox/2026-09-16.md]

**Shopping rule he was given:** confirm the listing explicitly says "MacBook Pro 14-inch 2021-2024" (or an equivalent 2021–2024 range) before buying — a bare "14-inch" label is not enough to guarantee fit.
