# Research-First Discussion

Chris emphasized that discussions about technical topics — particularly model architecture — should be grounded in researched information rather than general knowledge.

> "You looked up none of that information." ^[raw/inbox/2026-09-07.md]

This establishes a preference: when raising or responding to technical topics, the information should be looked up first, not spoken from memory or assumption.
