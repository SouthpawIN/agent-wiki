## Top 5 replacements to do first (payoff ÷ effort)
1. **Approval relay → `hermes serve` JSON-RPC (`approval.pending`/`approval.respond`) or `register_approval_transport`.** Retires the pending/*.json + .decision polling in `senter-bridge` (the most fragile, latency-prone code). First: `hermes serve --status`; then read `tui_gateway/methods_prompt.py:1104-1170`. Risk: needs `hermes serve` running; present_fn is in-process.
2. **CLAIM v2 + bridge `/post` done-lines → `hermes kanban`** (claim/heartbeat/reclaim/comment/complete/attach) and **fleet feed → `hermes kanban watch`**. Retires mkdir-claims, reaper, queue.md-as-lock, and the 2-minute `senter-fleet-feed` cron. First: `hermes kanban boards && hermes kanban list --json`. Risk: dispatcher lives in the gateway (`hermes gateway start`), claim TTL only via env var, every bot prompt must be rewritten.
3. **Heat chart SQL → `hermes sessions export --format jsonl -`.** Retires the raw `messages_fts` query that will break on the next schema migration. First: `hermes sessions export --format jsonl --after 2026-08-01 - | head`. Risk: none beyond per-profile looping.
4. **Bridge `/stt /tts /file /health` → dashboard routers `/api/audio/transcribe`, `/api/audio/speak`, `/api/files/read`, `/api/health`; composer injection → `file.attach`.** Retires ~4 route handlers. First: `grep -n '@router' ~/.hermes/hermes-agent/hermes_cli/web_routers/{audio,files,status}.py`. Risk: file-read allowlist scope differs; not live-curled yet.
5. **Scanner bots[]/skills[] → `GET /api/profiles` + `GET /api/skills?profile=X` + `skills-capabilities/.usage.json`; populate `hermes profile describe`.** Retires SOUL/SKILL.md parsing for those two halves (topics-wiki/ walk stays). First: `hermes profile list; hermes profile describe anser`. Risk: descriptions are empty everywhere — `--all --auto` is a mutating LLM sweep Chris should review.
